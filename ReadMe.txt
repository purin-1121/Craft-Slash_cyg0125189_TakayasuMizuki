== 遊び方説明 ==

<ゲームプレイ>
素材を集め武器を進化させ、自分の好きな武器で敵を倒そう！

道中には宝箱や岩、木などのオブジェクトがあります。
それらを攻撃すると破壊することができて、破壊するとアイテムがドロップします
また敵を倒すことでアイテムを入手できます

所持しているアイテムに応じて自動で武器が変わります
武器に応じてクールタイムや攻撃力、攻撃速度などがあるので自分の好きな武器を使ってください！

※現状敵やボスは1種類ずつしかいません
※武器は剣と銃の二つのみです
※銃は近くにあるBushを壊したら作れるようになっています

<エディットモード>
本ゲームには作成者用エディットモードが搭載されています

ここではマップ上にオブジェクトを配置したり、地形を変化させることができます
またオブジェクトを選択すると、数字を変化させるだけで移動させることができます

～ボタンの説明～
[Height]：頂点選択モードへ移行
[Select]：オブジェクト選択モードへ移行
[Enemy]：敵スポーン地点設置モードへ移行
[End]：エディットモード終了（強制保存）
[モデル設置]：モデルの名前を選んだ後に地面にクリックすると設置
[ステージ]：ステージの情報を更新できる入力ボックス表示
[モデル数値]：選択されているオブジェクトの位置やスケールを入力するボックス表示


== 操作方法 ==

<タイトルシーン>
[左クリック]：ボタン実行

<ゲームプレイ>

～プレイヤー～
[WASD]：移動
[SPACE]：ジャンプ
[左クリック]：攻撃
[右クリック]：宝箱開閉
[ドラッグ]：視点移動
[I]：インベントリ起動

～システム関連～
[Escape]：ポーズメニュー起動
[E]：エディットモード起動
[F2]：描画モード変更

～エディットモード～
[ボタンの上で左クリック]：ボタン実行
[オブジェクトの上で左クリック]：オブジェクト選択
[マウスホイール]：カメラ上下
[WASD]：カメラ移動
[Alt]：カメラの移動速度UP
[左クリック＆ドラッグ]：頂点選択
[右クリック＆ドラッグ]：視点移動
[入力ボックスの上でクリック]：入力ボックス選択
[キー入力]：選択された入力ボックスに入力

== 起動方法 ==
実行ファイル内にある「3DAction.exe」を起動してください
